# Design Specification: Model Name Cleansing and Normalization

**Date**: 2026-09-04  
**Author**: Antigravity Assistant & y_ohi  
**Status**: Approved  

---

## 1. Context & Motivation

In production monitoring of Cloudflare AI Gateway telemetry via Grafana Cloud (Prometheus and Loki), abnormal model identifiers were observed:
- Example: `kimi-k2.7-codemoonshotai/Kimi-K2.7-Code`
- Source: Requests routed through OpenCode via Cloudflare AI Gateway's `/compat` endpoint to custom providers (e.g. CommandCode / Moonshot API).
- Root Cause:
  - In streaming responses (`stream: true`), the upstream provider emits intermediate message chunks with `"model": "kimi-k2.7-code"` and a trailing usage chunk with `"model": "moonshotai/Kimi-K2.7-Code"`.
  - Cloudflare AI Gateway's SSE stream accumulator concatenates model strings across chunks rather than replacing them, yielding `"kimi-k2.7-codemoonshotai/Kimi-K2.7-Code"`.
  - This corrupted string is propagated via Cloudflare AI Gateway's OpenTelemetry trace export into graft-ai.
  - In graft-ai, the OTel pipeline currently takes `span.attributes["model"]` or `span.attributes["gen_ai.request.model"]` directly without passing through `normalizeModelName`.
  - Consequently, separate, deformed metric series and log streams are generated in Prometheus and Loki, fragmenting telemetry and cluttering dashboard filters.

---

## 2. Requirements & Goals

1. **Uniform Normalization**:
   - Both the Logpush pipeline ([`workers/src/transform.ts`](file:///home/y_ohi/program/private/graft-ai/workers/src/transform.ts)) and the OTel pipeline ([`workers/src/otel/spanlog.ts`](file:///home/y_ohi/program/private/graft-ai/workers/src/otel/spanlog.ts) and [`workers/src/otel/otlp-json.ts`](file:///home/y_ohi/program/private/graft-ai/workers/src/otel/otlp-json.ts)) must use the identical canonical model name normalization logic.
2. **Stream Concatenation Cleansing**:
   - Detect corrupted model strings generated by Cloudflare AI Gateway stream concatenation (e.g. `<req_model><vendor>/<upstream_model>`) and normalize to the canonical model identifier (e.g. `kimi-k2.7-code`).
3. **Prefix & Case Normalization**:
   - Continue stripping Cloudflare `@cf/` prefixes (`@cf/meta/llama-3-8b-instruct` -> `llama-3-8b-instruct`).
   - If a model string has an explicit single provider prefix (e.g. `moonshotai/kimi-k2.7-code` or `openai/gpt-4o`), strip the redundant provider prefix if appropriate, or keep it consistent with existing naming.
   - Lowercase model names to prevent cardinality duplication (e.g. `Kimi-K2.7-Code` -> `kimi-k2.7-code`).
4. **Fallback Handling**:
   - Empty, non-string, or whitespace-only model identifiers normalize to `"unknown"`.
5. **Universal Data Contract Compliance**:
   - Maintain strict Loki label constraints per `AGENTS.md`: `model`, `status_code`, `env`, `gateway`.

## 3. Detailed Architecture & Design

### 3.1 `normalizeModelName` Function ([`workers/src/transform.ts`](file:///home/y_ohi/program/private/graft-ai/workers/src/transform.ts))

The core normalization logic in `normalizeModelName(modelId: string | undefined | null): string`:

```ts
export function normalizeModelName(modelId: string | undefined | null): string {
  if (!modelId || typeof modelId !== "string") return "unknown";
  let trimmed = modelId.trim();
  if (!trimmed) return "unknown";

  // 1. Cloudflare Workers AI @cf/ prefix: @cf/<vendor>/<model> -> <model>
  if (trimmed.startsWith("@cf/")) {
    const withoutPrefix = trimmed.slice(4);
    const slashIndex = withoutPrefix.indexOf("/");
    trimmed = slashIndex >= 0 ? withoutPrefix.slice(slashIndex + 1) : withoutPrefix;
  }

  // 2. Cloudflare AI Gateway SSE stream concatenation bug:
  // Format: <request_model><provider_slug>/<upstream_model>
  // e.g. "kimi-k2.7-codemoonshotai/Kimi-K2.7-Code"
  const concatMatch = trimmed.match(/^(.+?)[a-zA-Z0-9_.-]+\/([a-zA-Z0-9_.-]+)$/);
  if (concatMatch) {
    const prefix = concatMatch[1].toLowerCase();
    const suffix = concatMatch[2].toLowerCase();
    if (prefix === suffix || prefix.includes(suffix) || suffix.includes(prefix)) {
      trimmed = prefix;
    }
  }

  // 3. Strip redundant provider prefix if single slash remains and prefix is known or general
  // e.g. "moonshotai/kimi-k2.7-code" -> "kimi-k2.7-code"
  const singleSlashMatch = trimmed.match(/^[a-zA-Z0-9_-]+\/([a-zA-Z0-9_.-]+)$/);
  if (singleSlashMatch) {
    trimmed = singleSlashMatch[1];
  }

  // 4. Canonical lowercasing
  return trimmed.toLowerCase();
}
```

### 3.2 OTel Pipeline Integration

#### 1. Loki Span Log Projection ([`workers/src/otel/spanlog.ts`](file:///home/y_ohi/program/private/graft-ai/workers/src/otel/spanlog.ts))
- Import `normalizeModelName` from `../transform`.
- In `canonicalLabels`:
  ```ts
  model: normalizeModelName(firstString(span, "model", "gen_ai.request.model")),
  ```
- In `projectLokiRecord`:
  ```ts
  model: normalizeModelName(firstString(span, "model", "gen_ai.request.model")),
  ```

#### 2. Prometheus Metric Generation ([`workers/src/otel/otlp-json.ts`](file:///home/y_ohi/program/private/graft-ai/workers/src/otel/otlp-json.ts))
- Import `normalizeModelName` from `../transform`.
- In `metricLabels`:
  When processing `key === "model"`:
  ```ts
  labels.model = normalizeModelName(stringAttribute(span, "model"));
  ```
